# REMS Pet Supplies and Accessories Management System

## Project Overview

The REMS Pet Supplies and Accessories Management System is a
web-based system designed to improve the daily operations of
a pet supplies and accessories business. It helps manage
products, inventory, sales, transactions, and user accounts.

## System Features

- User Authentication
- Role-Based Access Control
- Super Admin Management
- Admin Management
- Staff Management
- Product Management
- Inventory Management
- Point of Sale (POS)
- Sales and Transaction Management
- Customer Management
- Product Expiration Monitoring
- Reports and Dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Laragon
- Visual Studio Code
- Git and GitHub

## Installation and Setup

1. Clone or download the repository.
2. Place the project folder inside the Laragon www directory.
3. Open Laragon and start Apache and MySQL.
4. Set up the required MySQL database.
5. Import the appropriate SQL file, if provided.
6. Configure the database connection and local credentials.
7. Open the project using localhost in your browser.

## Security

Database credentials, user passwords, and private operational
records are excluded from the repository for security purposes.
